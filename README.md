# CRAVE - Dessert Bakery E-Commerce Platform

A complete, full-stack e-commerce web application built for a dessert bakery. This platform allows users to browse products, manage a wishlist, add items to a cart, and securely place orders. It also features a fully protected Admin Dashboard for managing the product catalog and processing customer orders.

## Features
* User Authentication: Secure login and registration using JSON Web Tokens (JWT) and encrypted passwords (bcrypt).
* Shopping Experience: Dynamic shopping cart and a synchronized user wishlist.
* Order Management: Customers can view their order history and current order status.
* Admin Dashboard: Role-based access control allowing administrators to perform CRUD operations on the product catalog and update order delivery statuses.
* Security: Environment variables used to protect sensitive database credentials and secret keys.

## Tech Stack (MERN)
* Frontend: React.js, React Router, Context API, HTML/CSS
* Backend: Node.js, Express.js
* Database: MongoDB & Mongoose
* Tools: Postman (API Testing), Git & GitHub
